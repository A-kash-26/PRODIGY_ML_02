# 🧑‍🤝‍🧑 Customer Segmentation using K-Means Clustering

This repository implements a **customer segmentation system** using the **K-Means clustering algorithm**. The project is part of **PRODIGY ML Internship – Task 02** and focuses on unsupervised learning to group customers based on their purchasing behavior.

---

## 📌 Project Overview

Customer segmentation helps businesses understand different customer groups and target them effectively. In this project, K-Means clustering is applied to customer data to discover meaningful segments.

**Key Highlights:**

* Unsupervised learning approach
* Uses K-Means clustering
* Elbow Method for optimal K selection
* Clear visualization of clusters

---

## 🧠 Algorithm Used

* **Algorithm:** K-Means Clustering
* **Type:** Unsupervised Learning
* **Library:** scikit-learn
